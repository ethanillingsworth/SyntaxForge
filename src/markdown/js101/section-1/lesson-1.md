
# If ... then

If statements are used run code only if a check passes as true an example of a check would be as such:

```js
if (a === 10) {
    // Only run if a is 10
}

// Run this no matter what!
```

## Using Math with If statements

You can also use math within your if statements as well.

```js
let a = 57

let b = 50

if (a === b + 7) {
    console.log("a is equal to b + 7")
}

console.log("a and b is any value")

```
