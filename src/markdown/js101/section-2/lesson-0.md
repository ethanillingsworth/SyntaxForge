# Math Constants

JavaScript's `Math` object includes several built-in constants that represent important mathematical values. These constants are **read-only**, meaning you cannot change them. They’re often used for calculations involving circles, logarithms, or large/small numbers.


## Common Math Constants

| Constant       | Description                                       | Example Value        |
| -------------- | ------------------------------------------------- | -------------------- |
| `Math.PI`      | Ratio of a circle’s circumference to its diameter | `3.141592653589793`  |
| `Math.E`       | Euler’s number (base of natural logarithms)       | `2.718281828459045`  |
| `Math.SQRT2`   | Square root of 2                                  | `1.4142135623730951` |
| `Math.SQRT1_2` | Square root of 1/2                                | `0.7071067811865476` |
| `Math.LN2`     | Natural logarithm of 2                            | `0.6931471805599453` |
| `Math.LN10`    | Natural logarithm of 10                           | `2.302585092994046`  |
| `Math.LOG2E`   | Base 2 logarithm of *e*                           | `1.4426950408889634` |
| `Math.LOG10E`  | Base 10 logarithm of *e*                          | `0.4342944819032518` |


## Examples

```js
console.log(Math.PI);      // 3.141592653589793
console.log(Math.E);       // 2.718281828459045
console.log(Math.SQRT2);   // 1.4142135623730951
```
