
# Combine Strings

Similarly to how you do math, you can also add strings together, we call this concatenation.

Example:
```js

console.log("Hello" + "World") // HelloWorld
```

This can be useful when you have variables that you'd like to use with other strings.

For example, If I want to say "Hello NAME" with NAME being a variable, it can be done like this.

```js
let name = "James"

console.log("Hello " + name) // Hello James

name = "Jasmine"

console.log("Hello " + name) // Hello Jasmine
```
