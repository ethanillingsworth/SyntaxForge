
# Console Logging

In JavaScript, you can use the `console.log()` function to display values in the console. This is helpful for checking your code, debugging, or understanding how data flows through your program.

## How to Log to the console

To log to the console call the function `console.log()`.

Example:

```js
console.log(value)
console.log("Hello World")
console.log(10)
```

`value` can be any data type, including numbers, strings, boolean values (true or false), null, and others.

All of which I will now go over briefly.

## Numbers

Numbers are well, any number, JS (JavaScript) doesnt differentiate between `ints`, `doubles`, or `floats`, they all just fall under the `number` type.

Examples:

```js
// Integer
console.log(10)

// Float / Double
console.log(3.14)

// Still both just numbers
```

## Strings

Strings are just pieces of text such as "Hello" or "This is a super duper long sentence and you should probably stop reading it.". There's 3 ways to make strings in JS, using `""`, `''`, and ``` `` ```. Double Quotes, Single Quotes and Backticks.

Examples:

```js
console.log("Double Quotes")
console.log("Single Quotes")
console.log("Backticks")
```

## Boolean Values

Boolean values represent either `true` or `false` and will be used extensively when we get to conditionals.

Examples:

```js
console.log(true)
console.log(false)
```

## Null / Undefined

Null in programming represents nothing, as in it has no value. Undefined is a JS exclusive, but is essentially the same as `null`.

Examples:

```js
console.log(null)
console.log(undefined)
```
